# Примеры работы

Разметка и отчёты скрипта на гелях из открытого набора GelGenie
([10.5281/zenodo.13218469](https://doi.org/10.5281/zenodo.13218469), CC BY 4.0). Жёлтые контуры — полосы, найденные
нейросетью, синие подписи — размеры полос маркера, зелёные — размеры полос образцов в п.н.; «?» — размер вне диапазона
маркера (экстраполяция).

| Файлы | Что показывает |
|---|---|
| `01_PCR_gel_8_wells_*` | гель с пустыми крайними лунками: агент добавил их, чтобы нумерация совпала с лунками |
| `02_ladder_gel_good_overlay.png` | маркер Invitrogen 1 Kb Plus по обоим краям, чистый гель |
| `03_smile_effect_overlay.png` | «улыбка» геля при маркере только с одного края: размеры в центре занижены |
| `04_degraded_lane5_overlay.png` | деградированная дорожка 5 с флагом смазанности |
| `05_hard_case_overlay.png` | перегруженный гель с сильной «улыбкой»: трудный случай |
| `06_mass_estimate_*` | оценка массы ДНК в полосах по маркеру NEB 1 kb Plus |
| `07_ladder_warning_*` | опорные полосы маркера не совпали: скрипт предупреждает, агент должен уточнить маркер |
