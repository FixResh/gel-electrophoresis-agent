# Тестовые гели

Пять снимков из открытого набора, на котором обучали GelGenie:
Aquilina M. et al., *Segmented Gel Electrophoresis Images used for Training GelGenie Models*, Zenodo,
[10.5281/zenodo.13218469](https://doi.org/10.5281/zenodo.13218469), лицензия
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Изменения: `25_NEB` и `29_NEB` переведены из 16-битного TIFF
в 8-битный PNG.

| Файл | Что на нём | Как запустить |
|---|---|---|
| `UVP02164June252019.jpg` | 8 лунок, маркер NEB 1 kb во 2-й, крайние лунки пустые | `--ladder neb_1kb --ladder-lanes 2 --add-empty-left 1 --add-empty-right 1` |
| `UVP01944May172019.jpg` | маркер в 1-й найденной дорожке, слабые полосы образцов | сначала без маркера, посмотрите разметку |
| `UVP02166June262019.jpg` | маркер и образцы со смазанностью в части дорожек | хороший пример флага смазанности |
| `25_NEB.png` | маркер NEB 1 kb Plus во всех лунках, заметная «улыбка» геля | `--ladder neb_1kb_plus --ladder-lanes 1,12` |
| `29_NEB.png` | маркер NEB 1 kb Plus во всех лунках, деградированная 5-я дорожка | `--ladder neb_1kb_plus --ladder-lanes 1,9` |

Маркеры на гелях `UVP…` определены по рисунку полос и отмечены как предположение. Для проверки агента на реальной
задаче используйте свои гели с известным результатом.
